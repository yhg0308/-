# Hog 解锁答案（key = Hog Project）

`python ok -u` 会按下面的顺序逐条提问。每条把 `输入：` 后面的内容敲进去即可；
带 `\n` 的表示这段代码有多行输出，需要分多次输入（每行一次）。
